# Demo data (Multi-Agent Assistant)

Fictional scenario metadata and a recorded kickoff replay for the static Cloudflare Pages showcase.

- `scenarios.json` — titles/requests (same fictional companies as the live app)
- `replay-kickoff.json` — timed events for the offline Pages demo
- Pages-served copies live under `site/data/` (root directory = `site`)

All people, companies, phone numbers, and credentials in these files are fictional.
